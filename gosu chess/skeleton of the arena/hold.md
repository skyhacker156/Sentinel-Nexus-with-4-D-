## Different Types of Wait States

### **Type 1: Processing Wait (Deterministic)**
```
Example: D-U-N-S number application
├─ Patrick's move: Submit application
├─ Opponent's move: D&B processes (5-30 days)
└─ Wait character: Deterministic (will happen, just slow)

Board status during wait:
  ⏳ Waiting for D&B processing
  ✅ No action needed from Patrick
  📅 Check back in 7 days
  🎯 Next move ready to execute when D-U-N-S arrives
```

### **Type 2: Approval Wait (Conditional)**
```
Example: Divvy card application
├─ Patrick's move: Submit application with EIN
├─ Opponent's move: Approve or deny (1-3 days)
└─ Wait character: Conditional (might be denied)

Board status during wait:
  ⏳ Waiting for Divvy decision
  ⚠️ Might be denied (backup plan: Ramp)
  📅 Check back in 2 days
  🎯 If approved: Continue to move 3
  🔄 If denied: Execute backup (Ramp application)
```

### **Type 3: Market Wait (Opportunistic)**
```
Example: Waiting for D-U-N-S before applying to Net-30 vendors
├─ Patrick's move: Apply for D-U-N-S
├─ Opponent's move: D&B creates number (5-30 days)
├─ Meanwhile: Other moves possible on different parts of board
└─ Wait character: Opportunistic (can do other things)

Board status during wait:
  ⏳ D-U-N-S pending (can't do Net-30 yet)
  ✅ But can work on other strategies simultaneously
  🎯 Move on different part of board:
     → Set up email (different piece)
     → File provisional patent (different piece)
     → Build website content (different piece)
  📅 Check D-U-N-S status weekly
```

### **Type 4: External Event Wait (Uncontrollable)**
```
Example: Waiting for USPTO examiner to review patent
├─ Patrick's move: Submit patent application
├─ Opponent's move: Examiner reviews (6-18 months)
└─ Wait character: Uncontrollable (completely external)

Board status during wait:
  ⏳ Patent under examination (6-18 months)
  ❌ No way to accelerate (external process)
  ✅ Focus on building business proof-of-concept
  🎯 Meanwhile, execute entire business strategy
  📅 Respond when office action arrives
```

## The Evaluation System

### **Chess Position Evaluation**

```
Chess uses centipawns:
├─ +100 = one pawn advantage (small edge)
├─ +300 = three pawns (significant advantage)
├─ +500 = rook advantage (winning)
├─ +1000 = queen advantage (overwhelming)
└─ Allows precise comparison of positions

Example:
"After 12.Nxe5, White is +1.5 (1.5 pawns better)"
├─ Objective measurement
├─ Comparable across games
├─ Helps identify best move
└─ Can track evaluation over time
```

### **gosu chess Strategy Evaluation**

```
gosu chess uses +score:
├─ +0.5 = weak option (barely acceptable)
├─ +1.5 = decent option (reasonable choice)
├─ +2.3 = strong option (very good)
├─ +2.8 = excellent option (near optimal)
└─ Allows precise comparison of strategies

Example:
"Strategy 3 (Full Replace) scores +2.3"
├─ Objective measurement
├─ Comparable across games
├─ Helps identify best strategy
└─ Can track outcomes vs predictions

After game:
"Strategy 3 predicted +2.3, actual outcome +2.5"
├─ Evaluation was accurate
├─ Actual cost lower than estimated
├─ Time on target
└─ Pattern validated for reuse
```

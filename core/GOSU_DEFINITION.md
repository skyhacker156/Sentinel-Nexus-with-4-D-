# Gosu — Canonical Meaning

Literal breakdown:
- Go (高) = high
- Su (手) = hand / skill

Full translation: "High-handed one" → master, expert, one of supreme skill.

In modern usage:
Gosu = One whose mastery is so complete it commands respect without challenge.

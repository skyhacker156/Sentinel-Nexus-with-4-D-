\[
\forall S,\;
\left(
\frac{d}{dt}\,\mathrm{DoF}(S) < 0
\;\land\;
\frac{d}{dt}\,\mathrm{Noise}(S) \le 0
\right)
\;\Rightarrow\;
\exists\, C \;\text{such that}\; S \xrightarrow[]{t} C
\]

Informal reading (do not publish with it)
For any system 
𝑆
S, if its degrees of freedom decrease over time and noise does not increase, then the system converges toward a stable configuration 
𝐶
C without requiring external persuasion or optimization.
